# ProgressiveClans

Плагин кланов для Paper/Spigot (1.21.x).

## Возможности

- Создание кланов
- Управление участниками
- Клановые территории
- Чат клана

## Установка

1. Скачай JAR из Releases.
2. Положи в plugins/ сервера (Paper 1.21.x).
3. Перезапусти сервер.

## Сборка

bash
gradle shadowJar


JAR: build/libs/ProgressiveClans-1.0.0-all.jar.

## Требования

- Paper/Spigot 1.21.x
- Java 21
